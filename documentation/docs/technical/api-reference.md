# API Reference

All requests to protected endpoints must include the `Authorization` header with a valid API key.

```http
Authorization: Bearer <API_SECRET_KEY>
```

## Endpoints

### `POST /api/v1/eval/trigger`
Triggers a new evaluation run.
- **Body:** `{ "feature_id": "string", "trigger_type": "string" }`
- **Response:** `202 Accepted` - `{ "run_id": "uuid", "status": "pending" }`

### `GET /api/v1/eval/{run_id}`
Retrieves the status and metrics of a specific evaluation run.
- **Response:** `200 OK` - Returns the `EvalRun` object including accuracy, latency, and test case results.

### `GET /api/v1/reports/{curr_run_id}/diff/{base_run_id}`
Generates a raw HTML diff report comparing two runs.
- **Response:** `200 OK` - `text/html` payload generated by Jinja2.

### `POST /api/v1/webhooks/github`
Listens for GitHub PR events. Automatically authenticates via `X-Hub-Signature-256` HMAC validation.
